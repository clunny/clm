## Intent

`20261101-architecture-review` adds `clm architecture` and the web app's Architecture view. The CLM panel's Capabilities tab (`plugin.panel/capabilities-tab`) shows `clm capabilities` read-only; an Architecture tab drawing `clm architecture` and an entry's page the same way would let the architect read it beside the chat, as the capability reviewer can.
