`watch-beside-chat` is Claude Code's alone, since neither the Codex CLI nor the Antigravity CLI lets a plugin draw a pane (checked 2026-11-12, `any-agent-harness`). When one of them offers an interface extension point, or through an editor extension that hosts the agent, show the same views there, from `clm view --format json`, as the panel does.
