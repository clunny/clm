AI assistants recommend what other sites say about a tool as much as what its own site says. These steps happen outside this repository, under the operator's own accounts. Nothing in the build waits on them.

1. **The GitHub repository `clunny/clm`:** set its description to the site's one-line description ("Declare the intent. AI builds the code to match. CLM keeps it matching."), its website to `https://clm-app.dev`, and topics such as `claude-code`, `claude-code-plugin`, `spec-driven-development`, `ai-coding`, `ai-agents`, `requirements`, `developer-tools`. Upload the site's social card (`web/site/public/`, once built) as the repository's social preview.
2. **Listings:** submit the plugin to the Claude Code plugin directories and marketplaces that take submissions, and propose CLM to "awesome" lists for Claude Code and AI-assisted development, each linking `https://clm-app.dev`.
3. **Your own writing:** the blog posts on `me.cldatatech.com` and the LinkedIn posts link to `https://clm-app.dev` (and to `https://clm-app.dev/guide/quickstart` for trying it), and use the same words for CLM as the site, so search and assistants tie them together.
4. Delete this item when you judge it done.
