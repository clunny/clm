Intent

Problem. Building the plugin's first slice exposed places where its spec is wrong or silent:
  • label-guard blocks reads like gh pr list --label spec-approved.
  • label-guard misses GraphQL label IDs.
  • binary-shim contradicts the Design when there's no binary.
  • session-status sees no state from a subdirectory.
Outcome. The guard judges each command segment; the shim says the guard is off; session-start walks up to the git root.

plugin · Requirements

label-guardModified
It SHALL exit 2, naming humans-review-intent, when the command contains spec-approved and one of -l, --label or /labels contains addLabelsToLabelable, or a segment that contains spec-approved and runs gh pr|issue edit|create with a label flag, or a writing gh api call.

binary-shimModified
When no binary can be had it SHALL cache nothing, and exit 1 for hook session-start, say the CLM state and the spec-approved guard are unavailable and exit 0; for other hooks, exit 0 silently; otherwise exit 1.
