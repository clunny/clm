Plugin

status: active · depends_on: check, context, orchestrator, sync

Contract

The Claude Code plugin clm, installed from this repo's marketplace. It provides the clm command on the Bash tool's PATH; hooks that call clm hook <name>; skills propose and implement; and the spec-auditor subagent.

Design

bin/clm is a POSIX sh shim. It runs, in order of preference: $CLM_BIN; the cached binary for its version; a fresh, checksum-verified download from the release.

Change 1 · Design paragraph modified
