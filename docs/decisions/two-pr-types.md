---
title: "Spec PRs and code PRs"
date: 2026-10-21
status: accepted
---

*Spec PRs* (changes/, specs/) get human review, gated by blast radius. *Implementation PRs* are AI-only and auto-merge when deterministic checks pass. A frontier/`specd` status lets approved-but-unbuilt spec live on `main` without counting as drift.
