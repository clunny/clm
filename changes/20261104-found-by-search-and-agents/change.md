# Found by search and agents

## Intent

Make `clm-app.dev` easy to find in web search and in AI search (ChatGPT, Claude, Perplexity), and easy for agents to read and use: crawler and agent files generated from the guide, page metadata, an FAQ written for the questions people ask, a clear GitHub link with its stars, a refreshed guide, and a plugin that downloads its binary without `gh`.
