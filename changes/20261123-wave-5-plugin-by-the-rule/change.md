## Intent

Wave 5 of phase 5 of `backlog/a-passing-check-proves-less-than-the-spec-claims.md`, its branch B of two: `plugin`, `plugin.agents` and `plugin.panel` (the `plugin/` skills, agents, commands, hooks files and `bin/clm` shim, and the `plugin-panel/` TypeScript) are each brought, in one pass and one delta, to the rule for a requirement (`requirements-state-what-the-contract-shows`). Each requirement now states what the code shows at the boundary: what the shim does and prints for each way it can fail, which files and keys Claude Code and Codex read, the agents' frontmatter, and what the panel draws, runs and answers. Scans of skill, agent and source text are cut (`prompt-text-is-source`), and the faults the pass found in the code are mended by each component's build. Two clauses move between components of this branch: `launch-models` from `plugin` to `plugin.agents`, and the marketplace and `clm` hooks-file clauses from `plugin.panel/panel-package` to `plugin/package` and `plugin/hooks-wired`. Branch A, `20261123-wave-5-hooks-by-the-rule`, holds `plugin.hooks`, `plugin.hooks.guard` and `plugin.hooks.guard.shell`; no clause moves between the two branches.

## What the pass found

Read against the rule and the code by one reader per component, then by one drafter per component that checked each entry against the code, with a builder check and three correction rounds. The builds mend, worst first:

- **The shim blocks every Bash call when `HOME` is unset** (`plugin/binary-shim`): with `HOME` unset and `XDG_CACHE_HOME` unset or empty, `plugin/bin/clm` aborts under `set -u`; under dash (Debian's and Ubuntu's `/bin/sh`) it exits 2, which Claude Code reads as a block of every Bash call, against `guard-fails-open`. With `HOME` empty it writes to `/.cache` and complains on stderr. It now fails as any other missing binary does: a hook exits 0, a command exits 1 with the reason.
- **The shim blocks every Bash call when it can't write its cache** (`plugin/binary-shim`, new scenario `a cache it can't write`): a failing hook writes the `.unavailable` mark with `: > "$cache/.unavailable"`; on an unwritable cache directory (a read-only `HOME`, a directory a `sudo` run made) or a read-only mark the failed redirection ends the script, and dash exits 2. The mark is now removed and written again (`rm -f`, then `touch`, each with `2>/dev/null`), and `chmod +x`, `mv -f` and `rm -rf` are silenced too, so such a hook still exits 0. A mark more than an hour old that `touch` can't update (a link to an unwritable place, a mark a `sudo` run left owned by root) no longer leaves every hook downloading again, up to 2x130 s per Bash call on a stalled network: the hour holds whenever the directory is writable. And `status` on an existing but unwritable cache directory says `can't write to <cache>`, not `can't create <cache>`.
- **The guard's hour after a failed download never ends in a busy session** (`plugin/binary-shim`): every failing hook rewrites the `.unavailable` mark, including one that skipped the download because of it. The mark is now written only by a run that tried the download.
- **A hook without a binary writes to stderr** (`plugin/binary-shim`): `sed`, `mkdir -p` and `mktemp` complain on stderr when `plugin.json` or the cache is missing.
- **A failing agent list throws the panel's session-start hook** (`plugin.panel/build-row-lifecycle`): `$.agent.list()` is called unguarded, where the runs should stay as they were.
- **A cut-short draw can read as "This session's directory no longer exists" and keep it** (`plugin.panel/superseded-draw`): `runClm` checks the directory before it tests the start error for `aborted`, and reads any rejected `stat` as missing, so the cached answer is wrong for the whole generation.
- **The panel draws escapes it should drop, and drops text it should draw** (`plugin.panel/views-panel`): a private CSI such as `\x1b[?25l` loses the text after it, and an escape with an intermediate byte, such as `\x1b(B`, is drawn.
- **A stop error survives a tab change** (`plugin.panel/queue-stop-buttons`): a tab change redraws without clearing it.
- **An older model ID reads wrong** (`plugin.panel/build-rows`): `claude-3-5-sonnet-20241022` reads `Sonnet 20241022` and `claude-3-opus-20240229` reads `Opus 20240229`, the date taken as the major version; an ID holding the form `claude-<major>[-<minor>]-<family>-<date>`, wherever `claude-` stands in it, now reads `<Family> <major>[.<minor>]` (`Sonnet 3.5`, `Opus 3`, and the Bedrock ID `us.anthropic.claude-3-5-sonnet-20241022-v2:0` reads `Sonnet 3.5`).
- **Tests that cite nothing**: the `req:` markers of `build-opens-panel` and `superseded-draw` sit outside every test, so no test cites either; `spec-slimmer`'s test checks only its tools, not its `name` and `description`.
- **Comments that name what doesn't exist**: the panel names `node-inspector` and `view/node-detail`; the skills name deleted decisions and requirements (split into `backlog/dead-decision-names-in-the-plugin-s-skills`).
- **Contracts that didn't match the code**: `plugin`'s said its tests read `plugin.agents`' files; `plugin.agents`' called every agent read-only and left the model to the skills, where three set `model: sonnet` and three have `Bash`; `plugin.panel`'s was wrong or incomplete in five places (no `--at origin/main` for `/clm:view <name>`, no checkout fallback, which runs it draws, the inspector and folded chains, which `clm` it runs). `plugin.panel`'s Design gave the price table as `effort`'s rows in the same order, where it merges them.
- **Behaviour no requirement stated**, now stated with a scenario each: the shim's exits when `CLM_BIN` can't run, its download time limits, its cache path, where its messages go and what it leaves behind; the `Stop` hooks' 30-second bound; that `/clm:view` exists (`plugin/view-command`, new); the panel's fetch line, widths, escapes, which `clm` it runs, its can't-start messages, rounds, model names, context, task tools, formats, pricing, the 200-run cap, resumes and orphans.
- **Prompt fixes the plugin's build makes** (`prompt-text-is-source`, each with its `Resolves:` trailer): the build skill's sentence for `--notes`, a refused `launched`, and `clm build release`; the propose skill's route for a bug in prompt wording, its list of cuts (a changed outcome), its sentence on renamed tests and on flags `clm apply` deletes; the triage skill's claims that `clm draft --finish` deletes every branch (`backlog/the-triage-skill-says-draft-finish-deletes-every-branch`, new) and that a landed branch is deleted by hand (`backlog/the-triage-skill-deletes-a-landed-branch-by-hand`, new).
- **Found and filed, outside this change's requirements**: the panel parses `effort`'s `prices.rs` as text (`backlog/the-panel-reads-effort-s-price-table-as-rust-source`, an idea); uncited panel tests that repeat others or guard cut clauses, and two test edits no requirement states (`backlog/the-panel-s-suite-holds-tests-no-requirement-cites`); the panel's spec and code run over their size budgets (`backlog/the-panel-s-spec-runs-over-its-size-budget`, an idea).
