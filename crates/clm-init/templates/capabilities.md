# Capabilities

The capabilities: what a person can do with this project, and why. The product manager owns this file.
An edit to it needs a human's review before it lands.
Each entry is a `### Capability: <slug>` block with a statement, a `#### Why` and at least one scenario.
Tests cite an entry as `req:capability/<slug>@<version>` (`clm hashes capability`); the format is in `clm guide spec-format`.
